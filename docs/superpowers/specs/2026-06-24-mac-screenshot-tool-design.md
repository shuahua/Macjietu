# 原生 Mac 截图工具设计

日期：2026-06-24

## 目标

构建一个原生 macOS 截图工具，第一版对标 CleanShot X 的核心体验：菜单栏常驻、全局快捷键唤起截图、区域框选、截图后悬浮预览、快速标注、复制、保存、贴图和本地历史记录。

第一版先不上架 App Store，但架构上预留未来上架可能。OCR 暂不实现，只保留服务接口位置。

## 范围

第一版包含：

- 菜单栏常驻入口。
- 全局快捷键唤起区域截图。
- 多屏半透明截图覆盖层。
- 鼠标拖拽框选区域。
- 截图完成后的悬浮预览小窗。
- 基础标注：矩形、箭头、画笔、文字、马赛克。
- 复制到剪贴板、保存到文件、贴到桌面、关闭。
- 本地历史记录，保存最近截图和元数据。
- 设置页：快捷键、默认保存位置、自动复制、历史保留策略。

第一版不包含：

- OCR。
- 云同步。
- App Store 沙盒完整适配。
- 滚动截图。
- 视频录制。
- 团队协作或分享链接。

## 技术架构

采用 SwiftUI + AppKit 混合架构。

- SwiftUI 负责设置页、历史记录页、标注工具栏、悬浮预览内容 UI。
- AppKit 负责菜单栏状态项、全局快捷键、全屏透明覆盖窗口、贴图窗口、窗口层级控制。
- ScreenCaptureKit 优先用于屏幕捕获。
- 必要时使用 CGWindowListCreateImage 或 CGDisplayCreateImage 作为兼容补充。
- 本地文件系统保存截图图片、缩略图和历史元数据。
- OCR 预留 OCRService 协议，后续可接入 macOS Vision。

## 核心模块

### AppCoordinator

统一管理应用状态和截图流程。负责响应菜单栏操作、快捷键事件、截图完成事件和错误状态。

### ShortcutManager

负责注册、更新和释放全局快捷键。设置页修改快捷键后通过该模块重新注册。

### CaptureOverlayController

创建跨屏透明覆盖层，处理鼠标按下、拖拽、释放和取消。输出标准化后的屏幕选区。

### ScreenCaptureService

根据选区生成截图图片。负责处理 Retina 缩放、多屏坐标转换和截图 API 差异。

### AnnotationEditor

承载截图编辑流程。维护标注图层，支持矩形、箭头、画笔、文字和马赛克。

### FloatingPreviewController

管理截图完成后的悬浮预览小窗。提供复制、保存、编辑、贴图和关闭入口。

### PinWindowController

把截图作为无边框窗口贴到桌面。支持拖动、缩放、置顶和关闭。

### HistoryStore

保存截图文件路径、缩略图路径、创建时间、尺寸、来源操作和编辑状态。第一版可使用 JSON 或 SQLite，优先选择实现成本更低、可迁移的结构。

### SettingsStore

保存快捷键、默认保存目录、是否自动复制、历史保留策略和默认截图行为。

### OCRService

第一版只定义协议，不接入实现。后续可增加 VisionOCRService，而不影响截图与编辑主流程。

## 数据流

1. 用户按全局快捷键或点击菜单栏截图入口。
2. AppCoordinator 检查屏幕录制权限。
3. CaptureOverlayController 创建多屏透明覆盖层。
4. 用户拖拽选择截图区域。
5. CaptureOverlayController 输出标准化选区。
6. ScreenCaptureService 根据选区捕获图像。
7. AppCoordinator 创建悬浮预览或进入标注编辑。
8. 用户选择复制、保存、编辑、贴图或关闭。
9. HistoryStore 保存图片、缩略图和元数据。
10. FloatingPreviewController 或 PinWindowController 更新对应窗口状态。

## 权限与设置

应用需要屏幕录制权限。首次使用截图功能时，如果没有授权，应展示说明页并提供打开系统设置的入口。

全局快捷键可能与系统或其他应用冲突。设置页需要在录入或保存时提示冲突，并允许用户重新录入。

第一版先按本地安装方式开发，但避免把关键能力直接耦合到非沙盒特性。后续如果要上架 App Store，应重点评估屏幕捕获权限、文件访问范围、全局快捷键和窗口层级行为。

## 错误处理

- 未授权屏幕录制：展示权限引导，阻止截图流程继续。
- 快捷键冲突：设置页提示冲突，不覆盖原有快捷键配置。
- 保存失败：保留内存图片，提示用户重试或选择新目录。
- 多屏坐标异常：回退到当前主屏截图流程，并记录内部日志。
- 剪贴板写入失败：提示失败，不影响保存和贴图操作。
- 历史记录写入失败：截图操作仍完成，提示历史保存失败。

## 后续扩展

- OCR：通过 OCRService 接入 macOS Vision。
- 滚动截图：新增 ScrollCaptureCoordinator，与普通区域截图流程隔离。
- 视频录制：新增 RecordingService，不复用静态截图服务的内部状态。
- App Store 上架：补充沙盒、权限、文件访问和审核约束适配。

## 决策记录

- 选择 SwiftUI + AppKit，而不是 Electron 或 Tauri，以保持原生体验和更可靠的窗口控制。
- 第一版采用 CleanShot X 风格，优先保证截图、悬浮预览、标注、复制、保存和贴图闭环。
- 第一版不做 OCR，避免扩大范围；仅保留服务接口便于后续扩展。
- 第一版先不上架 App Store，但避免过度依赖无法迁移的实现。
