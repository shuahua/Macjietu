# 供主代理处理的通用诊断 skill 草案

不创建或安装 skill。适用：磁盘化后仍遇资源上限、预览或恢复失败的图像管线。

1. 核验 AGENTS、git 未提交修改、运行进程路径及安装版本；不得覆盖现有改动。
2. 从日志定位最新真实用户失败会话，排除测试日志；按行号读取末段，不以“最新一行”代替故障证据。
3. 绘制采集、匹配、磁盘存储、预览、完整输出及错误恢复的调用链。逐项列出帧数、磁盘、像素、高度、工作内存限制与用户提示。
4. 使用 `python3 scripts/extract_long_capture_budget.py INPUT` 本地流式输出 JSONL；仅白名单数值，不包含日志正文或路径。旧日志未记录的预算分类不能推测成实测结论。
5. 对照真实生命周期推导峰值：串行阶段取最大值，真正重叠的资源才相加；计入行对齐、保留预览和编码临时空间。估算不得标成 RSS 实测。
6. 优先修复可证实的误计费和冗余副本，不盲目提高阈值。不擅自把单图改成多图。
7. 同尺寸/同帧数合成输入复现，测试旧式拒绝、新式接纳、逐像素一致性、预览分配、每类边界、候选拒绝保留旧快照及渲染失败恢复；运行完整测试和 diff 检查。
8. 交付证据文件和剩余实机限制。无用户确认不发布或打包。

验证脚本：以虚构旧格式与结构化 JSON 行输入，验证输出数值、行号、白名单过滤和坏行跳过。失败退出码非零；脚本不写输入、不上传数据。预算含义与根因仍由主代理判断。
